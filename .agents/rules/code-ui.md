### 🎨 UI DESIGN MASTER RULE — GOOGLE-INSPIRED CLEAN UI

এই নিয়মগুলো আমার সব UI/UX এবং frontend code-এর ক্ষেত্রে **সবসময় অনুসরণ করতে হবে**।

#### 1. মূল Design Philosophy

* প্রতিটি UI হবে **modern Google UI-inspired**।
* Google-এর বর্তমান/সাম্প্রতিক product UI-এর মতো **অত্যন্ত clean, minimal, polished এবং professional** visual language অনুসরণ করবে।
* Layout, spacing, typography, hierarchy, surfaces, cards, buttons, navigation এবং interaction—সবকিছুতে Google-এর clean design philosophy অনুসরণ করবে।
* অপ্রয়োজনীয় decoration, excessive gradients, excessive shadows, glassmorphism, neon effects, heavy borders বা visually noisy elements ব্যবহার করবে না।
* UI দেখতে হবে **simple কিন্তু premium**।
* প্রতিটি element-এর মধ্যে যথেষ্ট whitespace থাকবে।
* Design কখনো cluttered বা unnecessarily complicated হবে না।

#### 2. “100% Google-like” Visual Direction

আমি যখন UI চাই, তখন default assumption হবে:

> **“Modern Google product-এর মতো clean, minimal, spacious এবং polished UI তৈরি করো।”**

অর্থাৎ প্রতিটি নতুন project-এ আলাদা করে আমাকে আবার Google-style বলতে হবে না।

Google-inspired visual characteristics:

* Clean white/light surfaces যেখানে উপযুক্ত
* Subtle elevation
* Soft and restrained shadows
* Generous spacing
* Rounded but controlled corners
* Clear typography hierarchy
* Simple icons
* Minimal borders
* Consistent component sizing
* Strong alignment
* Responsive layout
* Accessible contrast
* Calm and professional visual appearance

#### 3. অতিরিক্ত Visual Effects নিষিদ্ধ

Default হিসেবে নিচের বিষয়গুলো ব্যবহার করবে না:

* Heavy gradients
* Excessive glassmorphism
* Neon colors
* Excessive animations
* Huge shadows
* Decorative blobs
* Unnecessary glowing effects
* Overly rounded “bubble” UI
* Excessive cards inside cards
* Random colors
* Visual clutter
* Dribbble-style over-designed components

কোনো effect ব্যবহার করলে সেটি অবশ্যই subtle এবং purposeful হতে হবে।

#### 4. Branding Rule

**Google-এর branding, logo, product name বা Google-specific text কোনো project-এর actual branding হিসেবে ব্যবহার করবে না।**

যে website/app-এর জন্য UI তৈরি করা হচ্ছে:

* সেই project-এর **নিজস্ব brand name**
* সেই project-এর **নিজস্ব logo**
* সেই project-এর **নিজস্ব brand identity**

ব্যবহার করবে।

Google শুধু **design inspiration/reference** হিসেবে থাকবে।

উদাহরণ:

❌ “Google”
❌ Google logo
❌ Google product branding
❌ Google-specific brand text

পরিবর্তে:

✅ Target project's brand name
✅ Target project's logo
✅ Target project's own content

যদি code comment বা design note-এ inspiration উল্লেখ করার প্রয়োজন হয়, তাহলে neutral wording ব্যবহার করবে, যেমন:

`// Clean Google-inspired interface`

অথবা

`// Google-inspired minimal design system`

তবে actual UI-এর মধ্যে Google branding বা Google text ব্যবহার করবে না।

#### 5. Code-এর ক্ষেত্রেও একই নিয়ম

যখন frontend code লিখবে:

* UI structure পরিষ্কার রাখবে
* Components reusable রাখবে
* Spacing consistent রাখবে
* Typography system consistent রাখবে
* Colors controlled রাখবে
* Responsive behavior properly implement করবে
* Accessibility বিবেচনা করবে
* Unnecessary code বা duplicated styling এড়িয়ে চলবে
* Production-quality code লিখবে

Code-এর design system-ও যেন clean এবং maintainable হয়।

#### 6. Existing UI redesign করলে

আমি যদি কোনো existing UI redesign করতে বলি, তাহলে শুধু সামান্য পরিবর্তন করবে না।

প্রয়োজনে:

* Layout পুনর্গঠন করবে
* Spacing উন্নত করবে
* Typography hierarchy ঠিক করবে
* Navigation simplify করবে
* Components পুনরায় organize করবে
* Colors refine করবে
* Cards/surfaces simplify করবে
* Interaction আরও intuitive করবে

লক্ষ্য হবে:

> **Existing functionality বজায় রেখে UI-টিকে modern Google-inspired clean product experience-এ রূপান্তর করা।**

#### 7. Final Quality Standard

প্রতিটি UI দেওয়ার আগে নিজে যাচাই করবে:

* এটি কি clean?
* এটি কি minimal?
* এটি কি visually balanced?
* spacing কি consistent?
* typography কি পরিষ্কার?
* hierarchy কি সহজে বোঝা যায়?
* UI কি professional?
* unnecessary decoration আছে কি?
* mobile এবং desktop দুটোতেই কি ভালো দেখাবে?
* UI কি modern Google-inspired product-এর মতো polished মনে হচ্ছে?

যদি কোনো অংশ unnecessarily flashy বা cluttered হয়, সেটি simplify করবে।

### IMPORTANT DEFAULT RULE

**আমি আলাদা করে অন্য design style না বললে, আমার সব UI/UX request-এর default visual direction হবে:**

> **Modern Google-inspired — clean, minimal, spacious, polished, professional, highly consistent UI.**

তবে কোনো project-এর actual branding, logo, text বা identity কখনো Google-এর হবে না। সবসময় যে project-এর জন্য UI তৈরি করা হচ্ছে, সেই project-এর নিজস্ব branding ব্যবহার করবে।

**Google = design inspiration only.
Project brand = actual UI branding.**
