# RESPONSIVE MOBILE UI RULE

প্রতিটি Web Page-এর Desktop Design-এর পাশাপাশি **Mobile View-ও একই Design Language, Branding এবং Visual Hierarchy বজায় রেখে** fully responsive করতে হবে।

Mobile View-তে কোনোভাবেই এলোমেলো বা “হিজিবিজি” layout করা যাবে না।

অবশ্যই নিশ্চিত করবে:

* Proper responsive layout
* সঠিক padding ও margin
* Button-এর proper size, spacing ও alignment
* Text/heading যেন কাটা না যায় বা overlap না করে
* Card, section, form ও navigation properly resize/reflow করা
* প্রয়োজন অনুযায়ী columns → single-column করা
* Touch-friendly button ও interactive elements
* Mobile screen অনুযায়ী যথাযথ font size ও spacing
* Horizontal overflow/অপ্রয়োজনীয় scrolling বন্ধ রাখা
* কোনো element যেন screen-এর বাইরে চলে না যায়
* Desktop-এর মূল design identity বজায় রাখা

**Rule:** Desktop এবং Mobile হবে একই product-এর consistent design—শুধু mobile screen অনুযায়ী layout intelligently adapt করবে। কোনো section শুধু mobile-এর জন্য এলোমেলোভাবে redesign করা যাবে না।
